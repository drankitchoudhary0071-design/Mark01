# Mark01

Personal AI agent **Mark** powered by Gemini 2.5 Flash.

## Setup

```bash
pip install -r requirements.txt
export GEMINI_API_KEY='your-api-key'
python mark.py
```

## Mark capabilities

- Run local Mac Terminal commands (safe subprocess)
- Write, read, and execute Python code in `~/MarkWorkspace`
- Search the internet for coding and trading strategy topics
- Send instant WhatsApp messages via pywhatkit
- Speak Hindi confirmations via gTTS
